# Common Vizier skills

The bundled skill pack is intentionally small and operational:

- filesystem-overview
- repo-maintenance
- debugging
- research-and-docs
- mcp-integration

These are exposed in the Python catalog at `vizier.skills` and are also documented
here for human use and packaging.

## Suggested usage

- Use `filesystem-overview` before large refactors.
- Use `repo-maintenance` before a release or cleanup pass.
- Use `debugging` for targeted failure analysis.
- Use `research-and-docs` to keep the docs grounded in source facts.
- Use `mcp-integration` when wiring up a new server configuration.
